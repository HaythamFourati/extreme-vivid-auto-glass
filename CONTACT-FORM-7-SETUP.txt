EXTREME VIVID AUTO GLASS — CONTACT FORM 7 SETUP
================================================

Tested against Contact Form 7 6.1.6.

IMPORTANT
---------
Contact Form 7 still sends through WordPress mail. If WordPress email is not
configured correctly, changing form plugins will not fix delivery by itself.
Configure a transactional SMTP/mail provider, then send a test from that
provider before testing this form.


1. CREATE THE FORM
------------------

In WordPress, go to:
Contact → Add New

Use this exact title:
Auto Glass Quote

The theme looks up the form by that exact title, so no shortcode ID needs to be
added to the theme. The theme also disables Contact Form 7's automatic paragraph
formatting for this title so the field grids and contact buttons render correctly.


2. FORM TAB
-----------

Replace everything in the Form tab with the block below — paste it exactly as
written, with no additions.

Note that the "Damaged glass" dropdown declares no options. The theme fills them
in from its glass_options list (inc/site-config.php), because the homepage
"What glass is damaged?" tiles pre-select this dropdown by exact value and the
two lists have to agree character for character. To add, rename or reorder a
glass option, edit glass_options — not this form. Anything you type into the
select tag here besides the placeholder is discarded.

Please accept the required terms before sending.

There is a field that the sender must fill in:
Please complete this required field.

There is a field with input that is longer than the maximum allowed length:
This entry is too long.

There is a field with input that is shorter than the minimum allowed length:
This entry is too short.

The remaining message fields can keep their Contact Form 7 defaults because this
form does not use uploads, dates, numbers, quizzes, URLs or acceptance fields.


5. ADDITIONAL SETTINGS TAB
--------------------------

Leave this tab blank.


6. SAVE AND TEST
----------------

1. Save the Contact Form 7 form.
2. Confirm the title is exactly: Auto Glass Quote
3. Clear any page/cache plugin cache.
4. Open the homepage and submit a real test.
5. Confirm both:
   - The website shows the custom success panel.
   - The message arrives in the To inbox.

If the website says the message could not be sent, or no email arrives, configure
SMTP/transactional email for WordPress and test the mail connection. Contact Form
7 does not provide an email delivery service.

Optional but recommended:
Install Flamingo if you want Contact Form 7 submissions stored in WordPress as a
backup. Contact Form 7 itself does not save submissions.
